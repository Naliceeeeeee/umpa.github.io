# UMPA Website

This is the static website for the Uganda Martyrs Pro-life Apostolate (UMPA).

## What is in this project?
- HTML pages for the site
- CSS and JavaScript assets
- Images and shared includes

## How to publish on GitHub
1. Create a new GitHub repository.
2. In the project folder, run:
   ```bash
   git init
   git add .
   git commit -m "Initial website upload"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. In GitHub, open Settings > Pages.
4. Set Source to GitHub Actions or Deploy from a branch.
5. For a simple static site, choose the main branch and root folder.

## Local preview
Open the site by launching the existing HTML files in a browser, or use a simple local server if you prefer.
